BILLING MANAGEMENT SYSTEM - PYTHON

Requirements:
- Python 3.10 or newer recommended
- Tkinter and SQLite (normally included with Python)

Run:
1. Extract the BillingSystem folder.
2. Open the folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: python main.py
   If that fails on Windows, try: py main.py

Files:
- main.py: application code
- billing.db: created automatically after running the app

Features:
- Add and remove products
- Automatic subtotal, discount, sample 5% tax, and grand total
- Save bills and items to SQLite
- Export bill as a text file
- View saved bill history

Note:
The 5% tax is a sample rate for a student project, not a statement of the applicable tax rate for any particular product.
